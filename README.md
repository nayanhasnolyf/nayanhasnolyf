## Selected work

**[SpotifyCares Support Agent](https://github.com/nayanhasnolyf/spotifycares-support-agent)** — a retrieval-grounded support agent that drafts replies from vetted historical responses, with a deterministic policy engine that forces human escalation for security and payment cases. Evaluated on 150 labelled examples: 36% intent accuracy against 12% majority-class and 16% TF-IDF baselines, with documented failure modes (over-escalation, empty retrieval, rate limits) and a Groq-to-Gemini fallback.
<sub>`Python` · `RAG` · `Groq` · `Gemini` · `Streamlit`</sub>

**[Indian Shopify Finder](https://github.com/nayanhasnolyf/indian-shopify-finder)** — a pipeline that discovers, verifies and extracts contact and brand data for Indian D2C Shopify stores. Scaled from 303 to **2,026 verified stores** in v2, with modular stages for sourcing, Shopify detection, confidence-scored India detection, extraction and dedup.
<sub>`Python` · `Beautiful Soup` · `Multithreading`</sub>

**[Spndx](https://github.com/nayanhasnolyf/Spndx---financial-dashboard-workspace)** — a deployed finance dashboard with Admin/Viewer role-based access, transaction CRUD, Recharts analytics and a Gemini assistant for natural-language financial analysis. 11-language i18n and dark/light theming. [Live demo](https://spndx-financial-dashboard-workspace.vercel.app)
<sub>`React` · `Node.js` · `Express` · `PostgreSQL` · `Gemini API`</sub>

**MolGenix** · 🏆 *Hack SurgeX runner-up* — a drug discovery platform built in 36 hours: ADMET property prediction, molecular docking simulation and ChromaDB vector search for compound similarity. Containerised with Docker Compose and deployable on AWS ECS and Hugging Face Spaces.
<sub>`Python` · `FastAPI` · `PostgreSQL` · `Docker` · `Gemini API`</sub>
